System Design
System Overview
The Product and Sales Management System is designed to organize and manage products, sales, users, suppliers, and customer-related activities. The system provides different user perspectives so that each type of user can access functions relevant to their responsibilities.
User Perspectives
The system has five user perspectives:
Admin
The Admin has the highest level of system access. The Admin manages users, products, suppliers, sales information, and sales reports.
Manager
The Manager oversees product and sales-related activities and monitors business operations.
Employee
The Employee performs operational tasks related to products and sales according to their assigned responsibilities.
Supplier
The Supplier perspective focuses on supplier-related activities and information about products supplied to the organization.
Customer
The Customer can search for products and access product-related information.
Main System Modules
The main modules of the system are:
User Management
Product Management
Sales Management
Supplier Management
Product Search
Sales Reports
Design Approach
The system is organized according to user roles. Each user perspective provides access to the functions required by that particular role. This helps keep the system organized and makes the interface easier to use.
Development Approach
The project follows an incremental development approach. The system is developed in smaller increments, allowing individual features and modules to be developed, tested, and improved throughout the project lifecycle.
