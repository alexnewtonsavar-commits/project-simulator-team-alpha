# Project Simulator
Product and Sales Management System
Project Overview
The Product and Sales Management System is a software system designed to help organizations manage products, users, suppliers, sales, and sales-related information in an organized and efficient way. The system provides different user perspectives based on the responsibilities of each user.
Project Objectives
Manage product information efficiently.
Record and manage sales transactions.
Maintain user and supplier information.
Provide different functions for different user roles.
Make product information easier to search and manage.
Generate and manage sales reports.
Improve the overall efficiency of product and sales management.
User Roles
The system includes five main user perspectives:
Admin — Manages users, products, suppliers, sales, and system-level information.
Manager — Oversees product and sales management and monitors business activities.
Employee — Performs assigned operational tasks related to products and sales.
Supplier — Manages supplier-related information and product supply activities.
Customer — Searches for products and interacts with product and sales-related functions.
