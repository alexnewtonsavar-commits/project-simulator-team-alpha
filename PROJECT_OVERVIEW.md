# Product and Sales Management System

## Project Overview

The Product and Sales Management System is designed to manage products, sales, users, suppliers, and customers in an organized and efficient way.

## User Perspectives

The system provides five user perspectives:

1. Admin
2. Manager
3. Employee
4. Supplier
5. Customer

## Main Objectives

- Manage product information
- Manage sales transactions
- Manage supplier information
- Manage users and roles
- Provide product search
- Generate sales reports
- Provide role-based user perspectives

## Development Approach

The project follows the Incremental Model. The system is divided into smaller functional increments that can be developed, tested, and integrated gradually.
