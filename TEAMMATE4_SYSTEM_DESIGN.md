System Design Contribution

System Overview

The Product and Sales Management System is designed to manage products, sales, suppliers, customers, and users through a centralized system.

User Perspectives

The system provides five different user perspectives:

Admin

Manager

Employee

Supplier

Customer

Main Modules

User Management

Product Management

Sales Management

Supplier Management

Customer Management

Reporting

System Design

The system uses role-based access so that each user can access features according to their responsibilities. The Admin has overall system control, while other users have limited access based on their roles.

Development Approach

The project follows the Incremental Model. Individual modules can be developed, tested, and integrated gradually until the complete system is built.
